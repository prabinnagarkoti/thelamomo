Nmap (also known as Network Mapper) is an open-source network scanning tool for network discovery and security auditing. Unlike Wireshark, Nmap is an active network tool — it sends hand-crafted IP packets to targets and examines the ICMP, TCP, or UDP responses in detail (Lyon, 2009).

From these exchanges, Nmap provides a number of key insights. It categorises each scanned port into one of three states: open (a service is actively listening and accepting connections), closed (the port is accessible but no service is running), or filtered (a firewall or packet filter is blocking probe responses, making the state indeterminate). This distinction is critical — filtered ports are particularly important because they may indicate a misconfigured firewall that is silently dropping traffic rather than explicitly rejecting it. Nmap also uses advanced banner-grabbing techniques to identify specific versions of services running (e.g., Apache 2.4.41 or OpenSSH 8.2p1) and can deduce the operating system of a target through OS fingerprinting, which significantly clarifies the risk profile of the network.
